모아노트 개인정보처리방침

시행일: 2026년 11월 25일

1. 수집하는 정보

모아노트의 개발자는 서버를 운영하지 않으며, 사용자의 문서·필기·계정 정보·사용 기록을 수집하거나 보관하지 않습니다. 광고와 분석 도구도 쓰지 않습니다.

2. 문서가 저장되는 곳

  • 문서는 사용자의 기기에 저장됩니다.
  • 사용자가 구글 드라이브나 원드라이브를 연결하면, 문서와 첨부 파일이 사용자 본인 계정의 저장 공간에 저장됩니다. 개발자는 이 파일에 접근할 수 없습니다.

3. 구글 계정 정보의 사용

구글 드라이브를 연결하면 모아노트는 다음 권한만 요청합니다.

  • 앱 전용 데이터 폴더(drive.appdata): 모아노트의 문서와 설정을 저장하고 불러옵니다.
  • 모아노트가 만들었거나 사용자가 모아노트로 연 파일(drive.file): 선택한 경우에만 씁니다.

이 권한으로 얻은 데이터는 문서를 저장하고 같은 계정의 다른 기기에서 불러오는 데에만 쓰며, 사용자의 기기와 구글 드라이브 사이에서만 오갑니다. 다른 곳으로 전송하거나, 제3자에게 제공하거나, 광고·AI 학습에 쓰지 않습니다. 모아노트의 구글 사용자 데이터 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

4. 마이크로소프트 계정 정보의 사용

원드라이브를 연결하면 앱 전용 폴더(Files.ReadWrite.AppFolder)에만 접근하며, 용도와 제한은 위 구글 드라이브와 같습니다. 로그인 유지에 필요한 토큰은 사용자의 기기에만 저장됩니다.

5. 함께 편집할 때

문서를 공유하면 참여한 기기끼리 직접 연결되어 문서 내용이 오갑니다. 연결 상대를 찾는 동안 공개 중계 서비스에 접속 정보(IP 주소 등 네트워크 정보)가 보일 수 있고, 함께 연결된 상대에게도 네트워크 주소가 보일 수 있습니다. 문서 내용은 연결된 기기 사이에서만 전송됩니다. 이미 상대가 받은 사본은 공유를 중지해도 회수되지 않습니다.

6. AI 기능

AI 기능은 사용자가 직접 연결한 경우에만 동작하며, 이때 질문과 선택한 문서 내용이 사용자가 고른 AI 서비스로 전송됩니다.

7. 정보의 삭제

앱에서 문서를 지우거나 클라우드 연결을 해제할 수 있습니다. 클라우드에 저장된 파일은 본인의 구글 드라이브·원드라이브에서 직접 지울 수 있고, 계정 설정에서 모아노트의 접근 권한을 언제든 철회할 수 있습니다.
